# <vscode project>

A responsive and accessible website for a fictional NGO, built as a practical project.

## 📌 About

This project is a single-page website designed to showcase the work and mission of a fictional non-governmental organization (NGO). It focuses on modern front-end development practices, including semantic HTML, accessibility, and responsive design.

## ✨ Features

- **Visual Feedback** – Interactive elements with hover states, transitions, and form validation feedback
- **Data Collection & Storage** – A functional form that collects and stores user-submitted data
- **Responsive Layout** – Hybrid layout using **CSS Flexbox** and **CSS Grid**
- **Semantic HTML** – Proper use of landmark elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, etc.)
- **Accessibility** – ARIA attributes, keyboard navigation support, sufficient color contrast, and alt text for images
- **Responsive Images** – Optimized and accessible image handling

## 🛠️ Technologies

| Technology | Usage |
|---|---|
| HTML5 | Structure and semantics |
| CSS3 | Styling, Flexbox & Grid layout, responsive design |
| JavaScript | Interactivity, form handling, data collection & storage |
